# ChamLing - Приложение для изучения языков

## Описание приложения

**ChamLing** — это полнофункциональное веб-приложение для изучения языков с возможностью создания, управления и продажи словарей. Приложение позволяет пользователям создавать собственные словари с переводами, добавлять слова с изображениями и примерами, изучать слова и покупать словари других пользователей.

## Технологический стек

### Frontend
- **React 19.2.0** — UI фреймворк
- **React Router DOM 7.9.4** — маршрутизация
- **React i18next** — интернационализация (английский, русский)
- **React Icons** — иконки
- **CSS3** — стилизация с поддержкой темной/светлой темы

### Backend
- **Django 4.2.14** — веб-фреймворк
- **Django REST Framework** — API
- **Django REST Framework Simple JWT** — JWT аутентификация
- **SQLite** — база данных (разработка)
- **Pillow** — обработка изображений
- **Unsplash API** — автоматический подбор изображений
- **MyMemory Translation API** — автоматический перевод

## Основная функциональность

### 1. Аутентификация и авторизация

**Регистрация пользователя:**
- Создание аккаунта с username, email и password
- Автоматическая выдача JWT токенов (access и refresh)
- Проверка уникальности email и username

**Вход в систему:**
- Авторизация по email и password
- Получение JWT токенов для доступа к защищенным API
- Сохранение токенов в localStorage

**Защищенные маршруты:**
- Все функции приложения доступны только авторизованным пользователям
- Компонент `ProtectedRoute` проверяет наличие токена

### 2. Управление словарями

**Создание словаря:**
- Название словаря (обязательно)
- Описание (обязательно для продажи)
- Язык-источник и язык-перевод
- Загрузка обложки словаря:
  - С устройства
  - По URL
  - Через камеру
  - Автоматический подбор через Unsplash API
- Опция продажи словаря:
  - Установка цены (минимум $0.50)
  - Возможность временного доступа
  - Установка длительности временного доступа (в днях)

**Просмотр словарей:**
- Страница "Мои словари" показывает:
  - Словари, созданные пользователем
  - Купленные словари
  - Статус: "На продажу", "Куплен"
  - Количество слов в каждом словаре

**Редактирование словаря:**
- Изменение названия, описания
- Обновление настроек продажи
- Изменение обложки

**Удаление словаря:**
- Удаление словаря со всеми словами (каскадное)

### 3. Управление словами

**Добавление слова:**
- Слово на языке-источнике (обязательно)
- Перевод (обязательно)
- Пример использования (опционально)
- Изображение:
  - Загрузка с устройства
  - Загрузка по URL
  - Через камеру
  - Автоматический подбор через Unsplash API
- **Автоматический перевод:**
  - Кнопка "Перевести" использует MyMemory Translation API
  - Автоматически определяет пару языков из словаря
  - Заполняет поле перевода

**Просмотр слов:**
- Список всех слов в словаре
- Поиск по словам
- Отображение: слово, перевод, пример, изображение

**Режим изучения слов:**
- Интерактивный режим изучения
- Показ слова с возможностью открыть перевод
- Показ примера использования
- Показ изображения
- Навигация: предыдущее/следующее слово
- Маркировка изученных слов

### 4. Магазин словарей (Маркетплейс)

**Просмотр доступных словарей:**
- Список всех словарей, выставленных на продажу
- Информация о каждом словаре:
  - Обложка (если есть)
  - Название и описание
  - Языковая пара (источник → перевод)
  - Цена
  - Количество слов
  - Иконка наличия изображения
  - Информация о временном доступе
- Разделение: словари пользователя показывают сообщение "Вы автор этого словаря" вместо кнопки "Купить"

**Покупка словаря:**
- Симуляция покупки через ввод кода (для тестирования: 1013)
- Выбор типа доступа:
  - Постоянный доступ
  - Временный доступ (с ограничением по дням)
- После покупки словарь появляется в "Моих словарях"
- Статус "Куплен" для купленных словарей

### 5. Настройки

**Язык интерфейса:**
- Переключение между английским и русским
- Сохранение выбора в localStorage

**Тема оформления:**
- Светлая тема
- Темная тема
- Сохранение выбора в localStorage

**Выход из аккаунта:**
- Очистка токенов
- Перенаправление на главную страницу

## API Endpoints

### Аутентификация
- `POST /api/auth/register/` — Регистрация
- `POST /api/auth/login/` — Вход
- `POST /api/auth/refresh/` — Обновление токена

### Словари
- `POST /api/dictionaries/create/` — Создание словаря
- `GET /api/dictionaries/` — Список словарей пользователя (включая купленные)
- `GET /api/dictionaries/<id>/` — Детали словаря
- `GET /api/marketplace/` — Список словарей в магазине

### Слова
- `POST /api/words/create/` — Добавление слова
- `GET /api/dictionaries/<id>/words/` — Список слов в словаре

### Покупки
- `POST /api/dictionaries/<id>/purchase/` — Покупка словаря

## Модели данных

### User
- `username` — имя пользователя (уникальное)
- `email` — email (уникальный)
- `balance` — баланс пользователя (для будущих расширений)

### Dictionary
- `owner` — владелец словаря (ForeignKey к User)
- `name` — название
- `description` — описание
- `source_lang` — язык-источник
- `target_lang` — язык-перевод
- `price` — цена (для продажи)
- `is_for_sale` — выставлен ли на продажу
- `allow_temporary_access` — разрешен ли временный доступ
- `temporary_days` — количество дней временного доступа
- `cover_image` — URL обложки (для обратной совместимости)
- `cover_image_file` — файл обложки
- `created_at` — дата создания

### Word
- `dictionary` — словарь (ForeignKey к Dictionary)
- `word` — слово
- `translation` — перевод
- `image_url` — URL изображения
- `example` — пример использования
- `created_at` — дата создания

### Purchase
- `user` — покупатель (ForeignKey к User)
- `dictionary` — словарь (ForeignKey to Dictionary)
- `access_type` — тип доступа ('permanent' или 'temporary')
- `purchased_at` — дата покупки

## Особенности реализации

### 1. Интернационализация (i18n)
- Поддержка английского и русского языков
- Все тексты вынесены в файлы переводов
- Автоматическое определение языка браузера
- Переключение языка в реальном времени

### 2. Темная/Светлая тема
- CSS переменные для цветов
- Переключение темы в настройках
- Сохранение выбора пользователя

### 3. Автоматический подбор изображений
- Интеграция с Unsplash API
- Автоматический подбор изображений для слов и обложек словарей
- Fallback на случай недоступности API

### 4. Автоматический перевод
- Интеграция с MyMemory Translation API
- Определение пары языков из словаря
- Кнопка "Перевести" для быстрого заполнения перевода

### 5. Валидация данных
- Frontend: валидация форм с отображением ошибок
- Backend: проверка данных через сериализаторы и модели

### 6. Обработка изображений
- Загрузка файлов с проверкой размера (макс. 5MB)
- Поддержка форматов: JPEG, PNG, WebP
- Предпросмотр изображений перед загрузкой
- Оптимизация для различных устройств

### 7. Управление состоянием
- React Hooks (useState, useEffect, useContext)
- Локальное состояние компонентов
- Глобальный контекст для темы

### 8. Тестирование
- Unit тесты для компонентов (Jest, React Testing Library)
- Тесты для форм добавления слова и словаря
- Тесты для валидации

## Процесс разработки

### Установка и запуск Frontend
```bash
cd cham_ling
npm install
npm start
```

### Установка и запуск Backend
```bash
cd cham_ling_app_BE
source venv/bin/activate
cd cham_ling
python manage.py runserver
```

### Управляющие команды Django
```bash
# Создание тестовых словарей
python manage.py create_test_dictionaries

# Добавление слов в существующие словари
python manage.py add_words_to_dictionaries --count 15
```
